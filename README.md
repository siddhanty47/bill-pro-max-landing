# Bill Pro Max — Landing Page

Marketing site for Bill Pro Max, the rental management platform for scaffolding businesses.

**Live:** [billpromax.com](https://billpromax.com) · **App:** [app.billpromax.com](https://app.billpromax.com)

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to out/
```

Built with Next.js 15 (static export), TypeScript, CSS modules and Lenis for smooth scrolling. See `CLAUDE.md` for structure and design rules.
